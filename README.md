# 星海公约 · 人间星海
# Stellar Covenant · Ordinary Lives

宇宙很大，先过好这一生。

面向普通玩家的原创星际悬疑叙事游戏。2077 年，归港站一名夜班工人被登记为死亡，食堂却依然收到他的早餐订单。选择维修员林渡、食堂经营者苏弥、快递员许照或法律援助律师简，从一个人的有限视角经历六起相互牵连的事件，直到晚年与身后留下的故事。

**当前默认版本为完整中文／英文的 2D 单机第一卷。** 不需要法律知识，不需要登录，无广告和付费体力。每位角色分别保存；切换人物进入另一条可能的人生，不把另一人的秘密或未来进度带进当前角色。

## 现在可以玩什么

- 四位主角，各有六幕独立视角、私人材料、生活选择与余波。
- 六起共同事件横跨 2077–2127 年，之后进入人物各自的生命尾声。
- 点击场景搜集记录、理解矛盾、作出生活选择；推理可以重试，无时间惩罚。
- 早年的记录与调查会影响最后的居民安置：共同保障、临时安置或家庭分别安置；另有个人结局与六次选择的手记。
- 简可进入旧版六案的双语叙事改编，法律是人物世界中的另一条线。
- 休息舱有空间站对接、翻牌、调频和呼吸放松，均非主线门槛；可以给自己放假。
- 中英文切换覆盖当前剧情、提示、卷宗、小游戏、结局与存档界面。
- 自动保存、上份备份恢复、JSON 导入导出；坏存档暂停覆盖并提示处理。

这不是全部 NPC 均已可玩的开放世界；目前使用 2D 场景点击与文字叙事，没有自由行走、实时日程、配音、3D 或多人联机。具体范围与后续推进见 [世界设计与路线图](docs/WORLD_ROADMAP.md)。

## 运行与同步

保留仓库目录后直接打开 `index.html`，或在根目录运行：

```bash
python3 -m http.server 8766
# 打开 http://127.0.0.1:8766/
```

只复制一个文件时，使用离线构建：

```bash
python3 tools/build.py
python3 tools/build.py --check
# dist/starsea.html 可以单独打开，无外部字体、媒体或网络依赖
python3 tools/sync_local.py /path/to/local/folder
```

同步工具覆盖指定目录内的 `index.html` 和 `星海公约-仲裁庭-v3-法庭剧场.html`，覆盖前自动备份，两份文件逐字节相同。GitHub 保留模块化入口及所需 CSS、JS，本地两份 HTML 由这些源码生成。不要手工维护三套内容。

存档属于浏览器与页面来源，设备、本地两个文件和 GitHub 网页之间不保证共享。使用“设置与存档”导出／导入迁移。清理浏览器数据也会删除自动备份。

## 代码与历史版本

| 位置 | 用途 |
| --- | --- |
| `index.html`、`css/lives.css` | 新版入口、响应式界面 |
| `js/lives/content.js` | 双语人物、六幕故事、公共事件余波 |
| `js/lives/cases.js` | 原有六案的双语叙事改编 |
| `js/lives/model.js` | 独立角色进度、选择、世界结果与存档校验 |
| `js/lives/engine.js` | 场景、交互、小游戏、保存和导入导出 |
| `archive.html` | 上一版星图与庭审的历史入口，需保留整个仓库 |
| 其他原有 `js/`、`css/`、`assets/` | 旧版实现与素材，保留供回看和后续复用 |

新版使用独立的 `SS_LIVES_v1` 存档，不覆盖旧版庭审进度。旧版历史入口仍含中文专有内容；完整双语承诺适用于新的默认游戏。六份新卷宗是改编，未把旧法庭的全部质证机制和法条逐字迁入。

## 验证

```bash
node tools/test/lives-model.js
# 启动上面的服务器，并使 Playwright 可用后：
node tools/test/lives-browser.js /path/to/screenshots
```

模型检查四个人物各 64 种选择组合，共 256 条组合路径；这不等于 256 个分别手写的独立结局。浏览器检查中英文完整人生、六份卷宗、休闲操作、导入导出、异常存档、离线文件和手机尺寸布局。旧版测试仍保留，测试旧入口时需把 `SS_URL` 指向 `archive.html`，其断言不适用于新游戏。
