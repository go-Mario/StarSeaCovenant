# 星海公约：一个世界，每个人的一生

更新：2026-10-21。以下区分已实现的第一卷与后续目标。

## 第一卷已经怎样改了

入口由法律知识与太空史改成生活悬疑：**一个被登记为死亡的人，为什么还在订早餐？** 玩家先关心人，再接触记录、程序与制度；法律术语不再是理解剧情的门槛。

| 可玩人物 | 生活起点 | 能接触的材料 | 最亲近的人 |
| --- | --- | --- | --- |
| 林渡，维修员 | 值班与维修，想留住家人相处的时间 | 设备、时钟、维修记录 | 妹妹林遥 |
| 苏弥，食堂经营者 | 一份饭能不能送到真正需要的人手里 | 订单、食材、匿名就餐者 | 儿子苏禾 |
| 许照，快递员 | 送达与收入，也关心收件人是否还能被找到 | 签收、路线、交接记录 | 阿棠 |
| 简，法律援助律师 | 当事人需要先证明自己还活着 | 当事人授权、登记与处理记录 | 带教者陈岚 |

每人有六幕原创视角、十二份私人材料、六次二选一的生活抉择。每幕另有可接触范围内的交叉核对。选定后主线始终停留在这个人的视角；手记只显示已亲历的内容。换人重玩保留独立存档，呈现另一种可能，不拼接成同一轮全知视角。

## 同一个世界的六次回响

| 年份 | 共同事件 | 生活与悬疑的交织 |
| --- | --- | --- |
| 2077 | 第十三份早餐 | 被注销的身份、84 秒时钟偏差与仍然送出的饭 |
| 2078 | 没有乘客的渡船 | 空名册背后的乘客、债务与劳动转运 |
| 2083 | 甜水里的苦味 | 饮水污染、错位的报告与被责怪的食堂 |
| 2092 | 迟到十五年的来电 | 熟悉声音、旧档案、合成来电与授权边界 |
| 2106 | 最后一班归港 | 空间站退役，登记缺口里的居民该去哪里 |
| 2127 | 留给后来的人 | 谁来讲述旧事，哪些私人记忆应被公开 |

人物随后走到各自人生终点，交代留下的钥匙、餐桌、路线图或钢笔。不是“选错即死”，也不是每个人都成为宇宙英雄。

选择影响下一幕的公共余波与最后的世界结果。例如，早年留下可追溯记录、推动水污染调查、晚年提出共同核验，能一起支撑新的居民安置规则；缺少早年依据时，同一晚年诉求只能换来临时安排；选择逐户照顾则通过家庭完成具体搬迁。个人结局还回看六次选择与留给自己的休息。

目前分支采取有限公共结果与个人手记组合：三个安置结果、三类个人结局文案、各角色生命尾声与选择记录。四位主角各六次二选一，共 256 条组合路径，**不是 256 个完全不同的手写长篇结局**。

## 法律与休闲的位置

原来六案在简的“另一条主线·六份卷宗”中改编为完整双语：核雨、预警、无主巨物、未登记采矿站、南极界线、回信。先看发生了什么、材料说明什么，再选择处理方向；进一步解释放在展开区。它们是虚构故事的叙事改编，旧版完整法庭引擎和具体法律材料保存在历史入口，不能把本次改编说成完成了旧案全文翻译或法律终审。

休息舱提供对接、翻牌、调频和呼吸放松。它们没有倒计时惩罚，也不要求赢小游戏才能推进悬疑。每幕可以记录一次休息，这进入个人生活手记。旧版其他航天小游戏仍在历史版，不冒称已经全部迁入新版。

## 中文与英文

新的默认游戏所有当前可见内容均有中文和英文，包括谜题、错误提示、选择后果、卷宗、小游戏和存档操作。人物与剧情文本成对编写；按钮与提示在同一位置维护。程序检查文本对完整性和英文中的中文遗漏，浏览器检查英文实际界面；这不等于已完成外部母语编辑审校。

语言原则：正文先讲人和行动；专业背景在需要时解释；英文按句意和人物口吻写，不把中文语序机械搬过去。下一轮外部试玩应让两种语言玩家分别复述事件，检查“好理解”与“意思一致”，不要只数有没有译文。

## 先把这一卷做得值得换人重玩

当前实现是完整可走通的 2D 点击叙事第一卷，主要操作为读记录、理解矛盾、作选择。还没有自由行走大地图、实时 NPC 日程、丰富职业模拟或联网。

下一轮优先顺序：

1. 邀请 10–20 名非法律背景玩家试第一幕，记录他们能否不解释就说清失踪之谜、下一步做什么、为什么在乎这个人。人数是招募目标，尚未完成用户测试。
2. 根据反馈扩写“相遇与对话”，给四个人不同的操作体验：维修时校对时序、食堂分配匿名餐、快递复原路线、律师核对当事人诉求。先改善一幕，避免四条线都只是换一套文字。
3. 加入站内 3–5 个可探索房间、线索之间的连结与个人笔记。搜集让玩家形成假设，不靠堆大量文本增加时长。
4. 再把乔安、林遥、苏禾、阿棠、陈岚等逐个升级为可玩主角。每次新增一人必须有自己的欲望、知识范围、操作、生活选择与生命余波；不只复制已有主线。
5. 公共事件保持共同事实与时间。未来若加入同一世界多角色接续，需要单独设计分支时间线与锁定规则，不能直接把现在的独立存档混合。

## 上架与 3D 多人怎么逐步推进

最省返工的顺序：**2D 网页真实试玩 → 手机真机和平台最小样片 → 3D 单场景 → 2–4 人合作事件 → 再扩展多人世界。**

- 网页阶段继续使用现有静态托管和离线文件。先验证非法律玩家愿意继续、愿意换人；暂不为尚未验证的玩法搭账号服务器。
- 手机样片只移植“第十三份早餐”一个人物与一个休闲玩法，验证触摸、暂停恢复、中英文排版、导入导出。平台准入核查和技术移植分别推进，见 [上线计划](LAUNCH.md)。
- 3D 先建食堂／维修间一个场景。如果空间探索没有增加线索理解与相遇体验，就继续改善 2D，而不因“丰富版”三个字整套重写。
- 多人先让 2–4 名玩家分别持有不同材料，共同决定是否公开、如何交接。服务端负责共同事件、权限与结果一致；个人秘密与公开知识必须分开。先解决断线恢复与冲突选择，再扩大世界。
- 现在可复用的是事件、角色、双语文本和选择规则；DOM/CSS 界面不等于可直接用于微信小游戏或 3D 引擎。
